# Pinned trip Home shortcut

- Each real Trip Hub card has a winged pin. Select one trip; selecting another replaces it, selecting the same one removes it. Completed trips are eligible. The sample tutorial is not.
- The pin is stored for the signed-in account on the current app/browser installation, not shared across devices. It stores only a trip ID and display name, never a share token, access token, or signed URL.
- Both the Home wings and RAVEN Trips heading open the pin directly. Without a pin, they retain the Trip Hub list route.
- The loader says “Opening [trip name]…” with the centered R/green-dot animation. Retry, cancel, and View all trips prevent a stuck loading screen.
- On tap, verify the SDK session, obtain a short-lived capability from the existing server-side membership endpoint, and fetch only that trip's current metadata/link. Do not fetch receipt or album data on idle Home.
- Recheck owner/member identity before navigation. Missing/revoked trips clear only the stale pin and fall back to Trip Hub. Network failures preserve it and offer retry. Sign-out/cancel invalidates pending navigation. Registered account switches never inherit another account's pin.
